# MCP Server

This is a basic MCP server using FastMCP which is connected to Claude Desktop. 

A simple notes.txt file was created by Claude to add notes into it.

### Basic MCP Decorators

1. Tools
2. Resources 
3. Prompt


4 functions were coded for connecting mcp using @mcp:
1. add notes (tools)
2. read notes (tools)
3. generate summary (prompt)
4. getting the latest note (resource)

The MCP was connected to Claude Desktop using Local Extensions.
